# Style Guidelines

## Overview

Where explanations belong and where user docs live.

## Rules

### Comments

- Comments explain why, never what. Invariants and non-obvious git or Textual behavior carry docstrings on the functions named in the architecture and invariants notes; extend those rather than scattering comments.

### Docs

- README holds user-facing docs, including troubleshooting and platform notes. CHANGELOG.md follows Keep-a-Changelog. Dependabot alerts and security updates are enabled.
